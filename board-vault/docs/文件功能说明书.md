# 单板金样前端文件功能说明书

## 1. 项目边界

本项目只负责浏览器界面和接口调用，不包含以下后端能力：

- 数据库连接和表结构
- TSSCH 或 Excel 文件解析
- 文件临时存储
- 重复与冲突比对
- 审批密钥验证
- 正式入库与拒绝处理

查询、录入、审批三个页面均保留。后端完成后，通过环境变量和 `frontend/api.ts` 接入即可。

## 2. 文件职责

### 前端

| 文件 | 功能 |
| --- | --- |
| `frontend/GoldenSampleApp.tsx` | 主页面和交互状态，包含首页导航、查询、录入、审批视图。 |
| `frontend/api.ts` | 唯一的接口调用入口，保存请求地址、参数、响应类型和错误处理。 |
| `frontend/styles.css` | 全站布局、渐变发光入口、表单、表格和响应式样式。 |

### 页面入口

| 文件 | 功能 |
| --- | --- |
| `app/page.tsx` | 将首页转发到前端主组件。 |
| `app/layout.tsx` | 设置中文页面、标题、描述和分享图。 |

### 静态资源

| 文件 | 功能 |
| --- | --- |
| `public/favicon.svg` | 浏览器标签页图标。 |
| `public/og-golden-sample.png` | 网页分享预览图。 |

### 构建与测试

| 文件 | 功能 |
| --- | --- |
| `vite.config.ts` | 前端构建和页面运行配置。 |
| `worker/index.ts` | 页面运行入口，不包含业务接口。 |
| `build/sites-vite-plugin.ts` | 构建时打包站点元数据。 |
| `tests/structure.test.mjs` | 检查纯前端目录和接口适配层。 |
| `package.json` | 前端依赖和运行命令。 |
| `.env.example` | 后端基础地址配置示例。 |

## 3. 后端基础地址

前端读取以下环境变量：

```text
NEXT_PUBLIC_API_BASE_URL=https://your-api.example.com
```

- 前后端同域：留空，接口请求发送到当前域名。
- 前后端分离：填写后端完整地址，不要以 `/` 结尾。
- 跨域部署时，后端需要允许此前端域名访问。

## 4. 预留接口

### 查询正式记录

```http
GET /api/records?q=搜索词
```

成功响应：

```json
{
  "records": [
    {
      "component_name": "金样名称",
      "item_id": "器件ID",
      "manufacturer": "厂家",
      "feature_tag": "特征标识",
      "payload_json": "{}",
      "created_at": "2026-07-28T12:00:00.000Z"
    }
  ]
}
```

### 提交录入

```http
POST /api/submissions
Content-Type: multipart/form-data
```

表单字段：

| 字段 | 类型 | 必填 |
| --- | --- | --- |
| `componentName` | 文本 | 是 |
| `manufacturer` | 文本 | 否 |
| `featureTag` | 文本 | 否 |
| `tssch` | 文件 | 是 |
| `sheet` | 文件 | 是 |

后端应根据比对结果返回 `duplicate`、`conflict` 或 `pending`。

### 查询待审批记录

```http
GET /api/submissions?status=pending
```

成功响应：

```json
{
  "submissions": []
}
```

### 验证审批密钥

```http
POST /api/approval/verify
Content-Type: multipart/form-data
```

表单字段为 `key` 文件。验证成功返回 HTTP 200，失败返回 HTTP 401 或 403。

### 审批或拒绝

```http
POST /api/submissions/{submissionId}/decision
Content-Type: multipart/form-data
```

表单字段：

| 字段 | 内容 |
| --- | --- |
| `key` | 审批密钥文件 |
| `decision` | `approve` 或 `reject` |

批准成功可返回：

```json
{
  "affected": 10
}
```

## 5. 错误响应

所有接口失败时统一返回：

```json
{
  "error": "面向用户的错误说明"
}
```

在后端尚未接入时，前端会提示配置 `NEXT_PUBLIC_API_BASE_URL`，页面本身仍可正常浏览。
