# 需求样本：小组周报交接方式

本文件是可复现演练的虚构输入，不是外部调研结果。

## 用户目标

为 6 人小组选择一种周报交接方式，并给出一页决策说明。只比较“共享 Markdown 文件”和“在线表单”两种候选方案。

## 已确认条件

- 小组每周提交一次周报。
- 所有成员都能编辑共享目录中的 Markdown 文件。
- 当前不能新增付费订阅。
- 当前工作网络不能稳定访问外部表单服务。
- 周报必须包含本周完成、未完成原因、下周计划三项。
- 第一周先用一种方案试运行；试运行后再评估，不承诺永久采用。

## 验收标准

1. 清楚列出目标和约束。
2. 每个结论能对应本文件中的依据。
3. 比较两个候选方案，但不编造价格、可用性统计或外部产品功能。
4. 推荐一种方案，解释理由，并写出第一周的具体执行步骤。
5. 指出仍需确认的问题：共享目录的维护人尚未确定。

## 输入边界

此演练只使用本文件，不联网调研、不联系组员、不创建外部账号、不发送周报。
