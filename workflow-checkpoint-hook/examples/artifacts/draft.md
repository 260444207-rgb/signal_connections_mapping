# 周报交接方式草稿（演示样本）

目标是为 6 人小组选择第一周的周报交接方式。约束是不增加付费订阅，并包含本周完成、未完成原因、下周计划三项。

| 方案 | 已有依据 | 第一周适用性 |
| --- | --- | --- |
| 共享 Markdown 文件 | 所有成员都能编辑共享目录中的 Markdown 文件 | 已知具备访问条件 |
| 在线表单 | 当前网络不能稳定访问外部表单服务 | 访问条件尚不足以支持稳定试运行 |

建议第一周使用共享 Markdown 文件。这是基于当前访问条件的判断，未评估长期维护成本。

第一周先由小组确认共享目录维护人，再建立含三项必填内容的统一模板。每位成员填写本周周报；周末由小组检查信息是否完整，并记录协作问题，决定是否调整方案。

待确认：共享目录维护人。依据为 examples/input/requirements.md；此文件仅为文档演示样本。
